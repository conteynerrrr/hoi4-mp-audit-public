# HOI4 MP Audit

[Русский](README.md) | [English](README.en.md)



**Журнал игровых команд для разбора мультиплеерных партий в Hearts of Iron IV.**



Логгер сохраняет доступные игровые команды на компьютере хоста: от удаления юнитов и снаряжения до изменений производства и театров. После партии можно открыть отчёт, найти нужного отправителя и посмотреть последовательность команд по времени.



**Версия: 0.1 · Windows x64 · установка на компьютер хоста**



## Возможности



- **История команд.** Можно отслеживать удаления юнитов и складского снаряжения, изменения производственных линий, назначение заводов, операции с театрами и другие категории игровых команд. Подробность записи зависит от типа команды.

- **Настройка под вашу партию.** Категории и отдельные команды включаются независимо. Большинство настроек применяется во время игры, примерно за две секунды.

- **Фильтр распознанных команд ИИ.** Подтверждённые команды ИИ можно исключить из журнала. Команды с неизвестным источником не считаются ИИ автоматически.

- **Меньше однотипных записей.** Близкие приказы перемещения могут сохраняться одной серией. Внутри остаются отдельные времена, ID и параметры всех команд.

- **Автоматическое сжатие.** Лог обновляется во время игры. По умолчанию он делится на части по 4 МиБ, а закрытые части сжимаются в gzip.

- **Удобный просмотр.** HTML-отчёт с поиском, фильтрация по отправителю и экспорт в CSV. Сжатые журналы открываются без ручной распаковки.



Установка нужна только хосту. Остальным участникам скачивать логгер не требуется. Дополнительная среда разработки или Python пользователю не нужны.



## Скачать и установить



1. Скачайте **`HOI4_MP_Audit_0.1.zip` из раздела Releases**. Архивы `Source code` содержат файлы репозитория, а не готовую DLL.

2. Закройте игру и распакуйте скачанный архив в отдельную папку.

3. Скопируйте **`version.dll` и `mp_audit.ini`** рядом с `hoi4.exe`.

4. Запустите игру обычным способом. Папка `mp_audit_logs` появится автоматически.



```text

Hearts of Iron IV/

├── hoi4.exe

├── version.dll

├── mp_audit.ini

└── mp_audit_logs/

```



Если в папке уже есть `version.dll`, используйте установщик ниже: он проверяет принадлежность файла и сохраняет существующие настройки. Чужую DLL он заменять не будет.



<details>

<summary>Установка и удаление через скрипты</summary>



Откройте PowerShell в папке распакованного архива. Подставьте свой путь к игре:



```powershell

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -GameDirectory "C:\Games\Hearts of Iron IV"

```



Если логгер установлен этим скриптом, удалить его при закрытой игре можно так:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1 -GameDirectory "C:\Games\Hearts of Iron IV"

```



Установщик сохраняет существующий конфиг. При удалении логи и изменённые настройки остаются.



При ручной установке закройте игру и удалите из её папки добавленную вами `version.dll` логгера. Настройки и журналы можно оставить.

## Где логи и как их смотреть



Журналы находятся в **`mp_audit_logs` рядом с `hoi4.exe`**. Каждый запуск создаёт новый файл. Текущий `.jsonl` дописывается во время игры, закрытые части получают расширение `.jsonl.gz`.



Для создания отчёта откройте PowerShell в папке распакованного архива и выполните, указав свою папку логов:



```powershell

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\report.ps1 -LogPath "C:\Games\Hearts of Iron IV\mp_audit_logs"

```



В указанной папке появится **`mp_audit_report.html`** — откройте его браузером. По умолчанию отчёт показывает до 10 000 последних команд. Можно также указать один конкретный файл `.jsonl` или `.jsonl.gz`.



В отчёте доступны поиск, ник отправителя, источник команды и её параметры. В колонке **«Команд»** можно раскрыть подробности серии. Количество в серии означает число команд, а не юнитов; соответствие одному клику не подтверждается.



Полезные параметры скрипта:



| Параметр | Что делает |

|---|---|

| `-Sender "Nickname"` | Оставляет указанного отправителя |

| `-ExcludeEngineAI` | Скрывает подтверждённые команды ИИ |

| `-ExpandBatches` | Показывает каждую команду серии отдельно |

| `-Csv` | Создаёт CSV вместо HTML |

| `-MaxRows 20000` | Увеличивает число отображаемых команд |



## Настроить запись



Откройте **`mp_audit.ini`** в папке игры. В `[tracking]` значение `1` включает категорию, `0` отключает её.



| Настройка | За что отвечает |

|---|---|

| `Units` | Юниты, включая удаления |

| `Equipment` | Снаряжение и склад |

| `Production` | Производство |

| `Theaters` | Театры |

| `Politics` | События, исследования, фокусы и другие политические команды |

| `Movement` | Перемещения и стратегическая передислокация |

| `BattleOrders` | Фронты и боевые приказы |



**В стандартном профиле перемещения включены**, а удаления складского снаряжения/юнитов и одиночные/массовые перемещения/отмены дополнительно выбраны через `[commands]`. Боевые приказы включаются отдельно: `BattleOrders=1`. Готовые варианты описаны в **[PRESETS.md](PRESETS.md)**.



Отдельную команду можно отключить в `[commands]`. Например, чтобы не записывать выбор ответа в событии:



```ini

[commands]

CSelectEventOptionCommand=0

```



Фильтр распознанных команд ИИ включён по умолчанию: **`SkipEngineAICommands=1`** в `[audit]`. Для их записи установите `0`. Служебные счётчики фильтрации не создают периодических строк в журнале.



Все параметры и категории описаны в **[SETTINGS.md](SETTINGS.md)**. Точные названия команд перечислены в **[command_catalog.csv](command_catalog.csv)**. Для замены DLL, изменения пути логов или переключения наблюдения источников нужен перезапуск игры.



Готовые конфиги для разных задач, включая авторский профиль: **[PRESETS.md](PRESETS.md)**.

## Как понимать записи



**Ник показывает отправителя, а не подтверждённого человека-автора.** В частности, команды ИИ могут иметь отправителем машину хоста. Если источник определить не удалось, запись остаётся неизвестной. По одной такой записи нельзя обвинять игрока в гриферстве.



Лог фиксирует вход в исполнение команды. Успех действия и его результат отдельно не подтверждаются. Время в журнале — время исполнения, а не клика. Часть объектов отображается внутренними ID; названия юнитов, моделей и количество уничтоженного снаряжения могут отсутствовать. При аварийном закрытии игры последние записи могут не сохраниться.



## Совместимость



Поддерживаемая сборка: **Operation Postern v1.19.4.2.2da5**, Windows x64. Точное соответствие EXE проверяется автоматически. На другой сборке аудит не включается; после обновления игры потребуется проверка совместимости.
